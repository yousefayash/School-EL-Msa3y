# مدرسة المساعي الثانوية — Backend V1

تم تحويل الموقع من Frontend-only إلى نسخة بها Backend مركزي.

## ماذا تم؟
- طلبات التسجيل تُرسل إلى `/api/registrations` وتُحفظ على السيرفر في `data/database.json`.
- أي هاتف أو كمبيوتر يفتح نفس الموقع على نفس السيرفر يرى نفس طلبات التسجيل.
- لوحة الإدارة تستخدم Session آمنة عبر HttpOnly Cookie.
- تسجيل الدخول محدود المحاولات.
- كلمة المرور لا تُخزن في قاعدة البيانات؛ يتم التحقق منها باستخدام bcrypt.
- لا توجد مكتبات Native مثل `better-sqlite3`، لذلك لا توجد مشكلة node-gyp التي ظهرت سابقًا.

## بيانات الدخول
- Username: `admin`
- Password: `MasaiAdmin2026!`

يفضل تغييرها قبل نشر الموقع من خلال `.env`.

## التشغيل على Windows
1. ثبّت Node.js 20 أو أحدث.
2. افتح CMD داخل مجلد المشروع.
3. نفّذ:

```bash
npm install
npm start
```

4. افتح:
`http://localhost:3000`

## مهم للهواتف الأخرى
`localhost` يعمل على نفس الكمبيوتر فقط. لكي يدخل الهاتف من نفس شبكة Wi‑Fi:
- شغّل السيرفر على الكمبيوتر.
- استخدم عنوان IPv4 للكمبيوتر، مثل `http://192.168.1.5:3000`.
- اسمح لـ Node.js عبر Windows Firewall إذا طلب ذلك.

وللنشر على الإنترنت تحتاج استضافة تدعم Node.js. وقتها كل الطلبات ستدخل إلى نفس السيرفر.
